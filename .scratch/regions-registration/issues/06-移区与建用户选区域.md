# 06：移区与建用户选区域

**构建内容：** 管理员能按区域筛选用户列表，把选中的一个或多个用户挪到另一个区域，并在手动建用户时直接指定落到哪个区域。管理员只能在自己名下的区域之间移动；跨管理员移动等于转让归属，仍然只有超级管理员做得了。

**阻塞项：** 03 区域页与增删改；多语言支持（`.scratch/i18n/`）合并完成。开工前先确认多语言的接口错误返回形态已定型。

**状态：** ready-for-agent

- [ ] 移区接口替换掉现有的指派归属管理员接口，接受单个或多个用户
- [ ] 用户列表支持按区域筛选
- [ ] 用户列表支持选中多个用户批量移区
- [ ] 管理员移区时目标区域必须也归属于他自己，否则拒绝
- [ ] 跨管理员移区只有超级管理员做得了，走既有的指派能力
- [ ] 移区界面提示这会改变历史报表的区域数字
- [ ] 单个创建用户的表单可以指定区域，不指定时落操作者的默认区域
- [ ] 批量创建用户可以指定区域，与单个创建同一条规则
