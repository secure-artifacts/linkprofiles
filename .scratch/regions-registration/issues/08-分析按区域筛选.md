# 08：分析按区域筛选

**构建内容：** 数据分析多出最外层的区域筛选。不选区域时看到的是自己全部可见区域的汇总，选中一个就只看那一个区域，再往下才是账号和单个个人页。管理员因此能回答「我这批人表现怎么样」，而不必一个账号一个账号地看。

**阻塞项：** 02 归属改走区域单链；多语言支持（`.scratch/i18n/`）合并完成。

**状态：** ready-for-agent

- [ ] 分析接口新增区域筛选参数，与既有的账号、个人页参数构成层层收窄的关系，同时指定时以最内层为准
- [ ] 不带区域参数时的结果等于全部可见区域之和
- [ ] 区域指标等于该区域内全部账号指标之和，账号指标仍等于名下个人页之和
- [ ] 实现上先按个人页算出统一表现，再依次折叠成账号行与区域行，四层共用同一份底层结果
- [ ] 区域口径按用户当前所属区域计算，埋点事件与日汇总都不冗余区域字段
- [ ] 指名一个自己看不见的区域，与「它不存在」同一个响应
- [ ] 分析页的区域筛选器位置在账号筛选之前
- [ ] 区域筛选处写明移区后历史区域数字会变
