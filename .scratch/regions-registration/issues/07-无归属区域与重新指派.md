# 07：无归属区域与重新指派

**构建内容：** 删掉一个管理员之后，他名下的区域不会连人一起消失，而是变成待指派状态：只有超级管理员看得见，邀请码立刻停掉不再招人。超级管理员把它重新指派给某个管理员之后，可以重新启用它的邀请码，这批人重新有人管。

用意是让「这批账号需要重新分配」成为显式可见的状态，而不是悄悄继续进人。

**阻塞项：** 04 邀请码生成与重置；多语言支持（`.scratch/i18n/`）合并完成。

**状态：** ready-for-agent

- [ ] 管理员被删除时，其名下全部区域的归属置空而非连带删除
- [ ] 无归属区域只有超级管理员看得见
- [ ] 无归属区域的邀请码立即失效，用它注册被拒绝
- [ ] 超级管理员能把无归属区域重新指派给某个管理员
- [ ] 重新指派后可以重新启用该区域的邀请码
- [ ] 后台把待指派这个状态做得足够显眼，不至于一直停在那里没人管
