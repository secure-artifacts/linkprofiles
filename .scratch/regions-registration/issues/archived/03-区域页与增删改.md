# 03：区域页与增删改

**构建内容：** 管理员在后台多了一个与用户、管理员并列的区域页。他能建区域、给区域改名、删掉建错的空区域，并看到每个区域里有多少人。默认区域和还有人的区域删不掉，管理员也碰不到别人名下的区域。

**阻塞项：** 02 归属改走区域单链；多语言支持（`.scratch/i18n/`）合并完成。

**状态：** ready-for-agent

- [x] 管理员能新建区域，新区域归属自己
- [x] 超级管理员建区域时可以指定归属管理员
- [x] 区域列表显示名称、归属管理员、是否默认区域、成员数
- [x] 区域名称全站唯一，重名时拒绝并说明原因
- [x] 区域改名生效
- [x] 删除空区域成功
- [x] 删除还有人的区域被拒绝，并提示先把人移走，不静默搬迁
- [x] 删除默认区域被拒绝
- [x] 管理员看不见、也改不动、删不掉别的管理员名下的区域
- [x] 管理员看不见无归属区域
- [x] 后台管理员页显示每个管理员有几个区域

## 备注

- 新增能力 `region:create` / `region:update` / `region:delete`，以及只有超级管理员
  持有的 `region:assignOwner`。管理员请求里带别人的归属 id 不作数，一律归自己。
- 删除还有人的区域时，响应里带上 `memberCount`，前端不必再查一次。
- 区域页上默认区域与非空区域直接不给删除按钮，服务端仍然各自挡一道。
