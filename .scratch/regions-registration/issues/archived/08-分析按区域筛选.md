# 08：分析按区域筛选

**构建内容：** 数据分析多出最外层的区域筛选。不选区域时看到的是自己全部可见区域的汇总，选中一个就只看那一个区域，再往下才是账号和单个个人页。管理员因此能回答「我这批人表现怎么样」，而不必一个账号一个账号地看。

**阻塞项：** 02 归属改走区域单链；多语言支持（`.scratch/i18n/`）合并完成。

**状态：** ready-for-agent

- [x] 分析接口新增区域筛选参数，与既有的账号、个人页参数构成层层收窄的关系，同时指定时以最内层为准
- [x] 不带区域参数时的结果等于全部可见区域之和
- [x] 区域指标等于该区域内全部账号指标之和，账号指标仍等于名下个人页之和
- [x] 实现上先按个人页算出统一表现，再依次折叠成账号行与区域行，四层共用同一份底层结果
- [x] 区域口径按用户当前所属区域计算，埋点事件与日汇总都不冗余区域字段
- [x] 指名一个自己看不见的区域，与「它不存在」同一个响应
- [x] 分析页的区域筛选器位置在账号筛选之前
- [x] 区域筛选处写明移区后历史区域数字会变

## 备注

- 区域行由账号行**折叠**得出，不另查一次。恒等式因此按构造成立，不靠两处公式
  恰好写对。
- 区域筛选与账号、个人页筛选是 AND 复合，因此「以最内层为准」自然成立；三者
  对不上时落到「看不见」的同一个响应，不返回一个自相矛盾的空结果。
