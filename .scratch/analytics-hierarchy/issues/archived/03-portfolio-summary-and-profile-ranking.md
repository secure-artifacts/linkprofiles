# 总览汇总与跨账号个人页排行

Status: ready-for-agent

数据分析首页直接汇总全部可见个人页，并提供跨账号个人页排行；排行显示所属账号，可按联系点击、进入页面或联系率排序，点击个人页直接进入单页分析。账号汇总保留为可选辅助视角。

## 验收

- [x] 首页显示总指标和总趋势。
- [x] 首页个人页排行覆盖全部可见账号，且显示所属账号。
- [x] 排行可按联系点击、进入页面和联系率切换。
- [x] 点击排行项直接进入单页详细分析。
- [x] 账号汇总继续可用，但不再是必经路径。
- [x] 服务端测试覆盖可见范围、总计和跨账号排行数据。

## Comments

复用按个人页统一计算再折叠账号的现有查询，只为总览补趋势查询与个人页所属账号字段，没有新增第二套统计公式。
