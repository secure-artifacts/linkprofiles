# 全球国家每日分析

Status: ready-for-agent

在全量总览、账号汇总和单个人页分析中增加统一的全球国家视图，直接回答每天每个国家打开多少次，并分别点击了哪些联系方式。

## 验收

- [x] 地图可按打开次数、全部点击和联系点击切换着色。
- [x] 显示全部国家汇总，不以地图是否能点中作为唯一入口。
- [x] 国家汇总包含打开、全部点击、联系点击、主要流量来源和主要联系方式列。
- [x] 点击国家后显示每日趋势与每天的 WhatsApp、Messenger 等平台点击。
- [x] 国家日报覆盖全量总览、账号和单页三种分析范围，并沿用既有权限过滤。
- [x] 地图资产本地发布，不新增第三方地图网络请求。
- [x] 后端交叉汇总、前端渲染、类型与生产构建均有验证。

## Comments

国家识别继续使用本地 GeoLite2。图表复用 Recharts，地图复用仓库内置 SVG 路径；未引入 Mapbox、Leaflet 或在线瓦片服务。超过明细保留期后，日汇总仍保存国家总数，但已经无法识别具体目标条目的历史点击归入“其他”，不伪造平台归属。
