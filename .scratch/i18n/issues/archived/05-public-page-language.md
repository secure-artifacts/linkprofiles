# 05：公开页页面语言

**构建内容：** 所有者给每个个人页设定页面语言，公开页据此声明 HTML 语言并渲染固定文案。访客的浏览器语言不参与，理由见 ADR-0020。

**阻塞项：** 01、03

**状态：** ready-for-agent

- [ ] 个人页新增页面语言，非空，存量一律回填简体中文
- [ ] 新建个人页写入所有者的界面语言
- [ ] 编辑器在布局与主题同一区域提供页面语言选择器
- [ ] 公开页的语言声明与 og locale 取自页面语言
- [ ] 静音按钮的无障碍标签、Banner 图替代文本、显示名与简介为空时的回落改由 key 渲染；客户端脚本里切换后的那份标签同步改
- [ ] 公开页保持零 hydration，不下发任何客户端语言逻辑
- [ ] 地址不存在时的提示页固定英语
- [ ] HTTP 测试断言同一个个人页对不同请求头返回相同的语言声明
- [ ] 迁移测试断言存量个人页的页面语言非空且为简体中文
