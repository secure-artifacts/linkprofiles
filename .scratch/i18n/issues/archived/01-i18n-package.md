# 01：i18n 包骨架与语言协商契约

**构建内容：** 为全站提供统一的语言入口。此后任何包都能取到当前语言的翻译函数，也能把一个请求头归一化成七种受支持语言之一。本票不改变任何现有界面行为。

**阻塞项：** 无（可立即开始）

**状态：** ready-for-agent

- [ ] 新包位于依赖链最底层，shared、profile-ui、server、admin 都能依赖它
- [ ] 导出七个语言标签常量 `en`、`zh-Hans`、`fil`、`es`、`pt-BR`、`id`、`vi`，其余取值一律归一化为 `en`
- [ ] 导出 i18next 实例工厂；译文以可静态 import 的模块提供，不读文件系统
- [ ] 译文按后台、公开页、服务端报错三个命名空间拆分，消费方只加载自己那份
- [ ] key 由英文源文推导出联合类型，拼错时 typecheck 失败
- [ ] 对齐测试：每份译文的 key 集合与英文源文完全相等，且没有空串
- [ ] 协商测试覆盖命中、带权重、带地区后缀降级、完全不支持四种情形
- [ ] 首批只放英语、简体中文、菲律宾语三份，只含 03 需要的 key
