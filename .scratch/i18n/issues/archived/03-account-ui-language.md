# 03：账号界面语言与后台语言切换

**构建内容：** 账号持有者可以在后台把界面切成自己的语言，切换结果跟着账号走，换一台设备登录仍然生效。这是第一条端到端打通的路径。

**阻塞项：** 01

**状态：** ready-for-agent

- [ ] 账号新增界面语言，非空，存量一律回填简体中文
- [ ] 新建账号写入创建者的界面语言；初始化流程创建的超级管理员写英语
- [ ] 批量开号继承操作者的界面语言，输入格式不变
- [ ] 顶栏账号菜单提供语言切换，切换后写回账号
- [ ] 登录页与顶栏文案改由 key 渲染，三种语言下均正确
- [ ] 后台每个接口请求携带当前界面语言
- [ ] 归属管理员可改名下账号的界面语言，走既有归属校验；改不了非名下账号
- [ ] 迁移测试断言存量账号的界面语言非空且为简体中文
