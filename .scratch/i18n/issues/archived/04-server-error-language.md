# 04：服务端报错按语言返回

**构建内容：** 用户提交表单出错时，看到的是自己界面语言的提示；未登录或调用方是程序时固定英语。

**阻塞项：** 01、02、03

**状态：** ready-for-agent

- [ ] 服务端按请求携带的语言选择报错语言，无有效语言时用英语
- [ ] 使用固定实例配合按语言取出的翻译函数，不为每个请求新建实例
- [ ] 认证与账号相关路由的报错文案改 key
- [ ] 登录失败的报错固定英语
- [ ] 外部联系方式更新 API 的报错固定英语，结构化错误码不随语言变化
- [ ] HTTP 测试覆盖命中语言、不受支持的语言、未携带语言三种情形
