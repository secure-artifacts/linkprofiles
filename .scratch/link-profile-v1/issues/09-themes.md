# 09：六套主题

**构建内容：** 用户可以在六套配色之间切换，让页面符合自己的调性。任何一套套在任何一种布局上，文字都看得清。

**阻塞项：** 08 五种布局

**状态：** ready-for-agent

- [ ] Dawn、Harbor、Moss、Ember、Slate、Nocturne 六套主题全部可用，后台可切换并持久化
- [ ] 主题实现为一组 CSS 变量取值，结构不变；**圆角是主题的一部分而非全局常量**
- [ ] 三十种布局与主题的组合逐一验证文字对比度达到 WCAG AA
- [ ] 新账号默认使用 Dawn·晨
- [ ] 用户可上传背景图：上传后覆盖主题的背景渐变，主题的按钮色与文字色仍生效
- [ ] 背景图上叠一层暗度可调的遮罩，默认四成，保证文字对比度
