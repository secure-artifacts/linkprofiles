# 17：分享卡片与收录控制

**构建内容：** 把链接转发到 WhatsApp 或 Facebook 时，对方看到的是带头像和名字的预览卡片而不是一行光秃秃的地址；同时这些页面不会被搜索引擎收录。

**阻塞项：** 09 六套主题、10 媒体上传与处理

**状态：** ready-for-agent

- [ ] 公开页输出完整 og 标签：标题、描述与预览图
- [ ] 预览图取自用户的头像或头图，缺失时回落到与主题一致的占位图
- [ ] 输出 noindex 阻止搜索引擎收录
- [ ] **noindex 与 og 标签并行不冲突**：社媒爬虫仍能正常抓取卡片
- [ ] 爬虫抓取行为不产生埋点记录（与 12 的规则一致）
