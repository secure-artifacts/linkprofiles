# 07：个人页内容编辑

**构建内容：** 用户登录后台就能把自己的页面配起来：改显示名和简介，添加按钮并填上文字、选填的副标题和目标链接，拖拽调整顺序，标记哪些属于联系类渠道，启用社媒图标时只填号码不必懂 URL 格式。改完刷新公开页立刻生效。

**阻塞项：** 02 个人页最小可访问、03 超级管理员初始化与登录会话

**状态：** ready-for-agent

- [ ] 用户可修改自己的显示名与简介，公开页随之变化
- [ ] 按钮可增删改：标题、选填副标题、目标链接、is_lead 标记、来源透传开关
- [ ] 按钮可拖拽排序，顺序持久化并反映在公开页上
- [ ] **按钮不分组**：全部按钮共处一个有序列表，联系类与内容类可混排，页面上没有区段标题
- [ ] 公开页按 is_lead 呈现两级视觉：联系类为实心卡片，内容类为描边行；分级只由标记决定，与位置无关
- [ ] 按钮副标题留空时不渲染该行
- [ ] 单页按钮数量上限五十
- [ ] 社媒图标可逐个启用，清单仅含海外平台且不含任何大陆 app；用户填号码或邮箱，目标 URL 由系统拼装
- [ ] 用户不能修改自己的 short_name；管理员可以修改名下用户的
