# 14：数据分析读取

**构建内容：** 用户打开后台就能看到自己的页面到底有没有用：来了多少线索、点击率多少、访客在哪、用什么设备、哪个平台带来的最多、一天里几点最活跃。

**阻塞项：** 12 埋点写入

**状态：** ready-for-agent

- [ ] 呈现线索数、点击数、页面浏览数与点击率
- [ ] 线索定义为对联系类渠道的点击，由每条的 is_lead 决定；点击率为单按钮点击除以页面浏览，另有页面级汇总
- [ ] 维度可拆分：国家与城市、设备类型与操作系统、来源
- [ ] 趋势图支持预设区间与自定义区间；区间不超过两天时按小时聚合，否则按天
- [ ] 提供 24 小时分布图，将所选区间内的线索汇总到零至二十三点
- [ ] 底层一律存 UTC；后台提供展示时区切换，默认受众所在时区
- [ ] **切天与分桶按所选展示时区计算，不是服务器时区**；跨日边界的归属正确
- [ ] 用户只看得到自己的数据，管理员只看得到名下用户的，超级管理员看得到全部
