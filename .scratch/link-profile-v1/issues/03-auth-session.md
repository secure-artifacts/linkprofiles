# 03：超级管理员初始化与登录会话

**构建内容：** 运维把账号密码写进环境变量，首次启动系统自动建出超级管理员；重复启动不会重复创建。此后可以用这个账号登录后台，登录状态保持三十天，改密码后旧的登录立刻失效。

**阻塞项：** 01 工程骨架与测试底座

**状态：** ready-for-agent

- [ ] 首次启动读取环境变量创建超级管理员；库中已存在时跳过，重复启动幂等
- [ ] 账号 + 密码可登录；密码以 argon2 哈希存储，任何响应都不回传哈希
- [ ] 会话存库，通过 HttpOnly 且带 SameSite 的 cookie 维持，有效期三十天
- [ ] 登出后原会话立即不可用
- [ ] 修改密码后该账号的全部既有会话失效，需重新登录
- [ ] 未登录访问后台受保护接口返回未授权，不泄露资源是否存在
