# 16：short_name 墓碑与删除流程

**构建内容：** 用户被删除后，他印在名片上、挂在社媒简介里的旧链接不会把访客导到另一个陌生人的页面上。

**阻塞项：** 05 归属分权与无归属流转、10 媒体上传与处理

**状态：** ready-for-agent

- [ ] 删除用户时其 short_name 迁入墓碑并**永不释放**
- [ ] 访问墓碑中的 short_name 返回 404
- [ ] 新建用户或修改 short_name 时不得占用墓碑中已有的值
- [ ] 删除用户时其上传的媒体文件从磁盘移除，不留孤儿文件
- [ ] 删除用户时其埋点数据保留，历史汇总不断档
