# 02：个人页最小可访问

**构建内容：** 访客拿到一个 `域名/{short_name}` 地址就能看到这个人的页面：显示名、简介、头像位都在。地址写错则得到明确的 404，而不是空白或报错页。

**阻塞项：** 01 工程骨架与测试底座

**状态：** ready-for-agent

- [ ] 访问已存在用户的 short_name，返回服务端直出的完整 HTML，显示名与简介正确渲染
- [ ] 页面不做 hydration：响应中不包含 React runtime，客户端脚本仅为埋点预留的一小段
- [ ] 访问不存在的 short_name 返回 404
- [ ] short_name 大小写不敏感：不同大小写指向同一个页面
- [ ] 以 Classic 布局与 Dawn 主题渲染，缺少头像素材时以主题渐变填充该区域
- [ ] 关键 CSS 内联进文档头，头像位标记为高优先级加载
