# 13：来源追踪与透传

**构建内容：** 同一个页面可以带不同参数投到不同平台，后台就能回答「哪个平台带来的线索最多」这个问题。需要时还能把来源传给按钮指向的目标网站。

**阻塞项：** 12 埋点写入、07 个人页内容编辑

**状态：** ready-for-agent

- [ ] 个人页地址可携带 src 参数，其值随该次访问的页面浏览与点击一并记录
- [ ] src 值受字符集与长度限制，超出即丢弃，脏值不得进入数据库或后台图表
- [ ] 无参数访问记为未知来源
- [ ] 按钮可逐条开启来源透传，开启后跳转目标 URL 上会带上来源
- [ ] 超级管理员可设置透传的全局默认值
- [ ] src 清洗实现为 shared 包内的纯函数，并有覆盖注入类畸形输入的单元测试
- [ ] 已知取舍需在后台文案中说明：使用 src 而非 utm_source，第三方站点的分析工具无法直接归因
