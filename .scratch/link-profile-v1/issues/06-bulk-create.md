# 06：批量创建用户

**构建内容：** 管理员从表格里复制多行粘贴进来，一次建好几十个账号。个别行有问题不影响其余行，结果会直接告诉他第几行为什么失败，不必整批重来。

**阻塞项：** 05 归属分权与无归属流转

**状态：** ready-for-agent

- [ ] 接受制表符分隔的四列输入：用户名称、账号、short_name、密码
- [ ] 逐行处理：合法行照常创建，失败行跳过，不做整批回滚
- [ ] 返回结果列出每个失败行的行号与原因，例如账号已存在、short_name 非法、密码为空、列数不对
- [ ] 批量创建的用户归属于操作者
- [ ] 全部密码以 argon2 哈希入库
- [ ] 行解析逻辑作为 shared 包内的纯函数实现，并有覆盖各类畸形输入的单元测试
