# 12：埋点写入

**构建内容：** 从此每一次页面被打开、每一个按钮被点击都会被记下来，并且带上访客来自哪个国家哪座城市、用什么设备。社媒爬虫来抓分享卡片不会被算成访问，否则页面越受欢迎数据反而越难看。

**阻塞项：** 02 个人页最小可访问

**状态：** ready-for-agent

- [ ] 公开页每渲染一次写入一条页面浏览；每次点击写入一条点击记录
- [ ] **不做任何访客去重，全部纯计次**
- [ ] 按 User-Agent 识别爬虫，识别为爬虫则**直接不写记录**；页面与 og 标签照常返回
- [ ] IP 先用于查出国家与城市，**随后立即截断再落库**：IPv4 去掉最后一段，IPv6 去掉后 80 位
- [ ] 顺序不可颠倒：截断必须发生在地域查询之后
- [ ] 解析 User-Agent 得到设备类型与操作系统并落库
- [ ] IP 截断与 User-Agent 解析实现为 shared 包内的纯函数，各有覆盖边界情况的单元测试
- [ ] 点击记录关联到具体按钮或社媒图标，并标明是否计入线索
