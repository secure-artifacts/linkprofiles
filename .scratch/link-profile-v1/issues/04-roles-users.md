# 04：三级角色与用户管理

**构建内容：** 超级管理员可以创建和删除管理员，管理员可以创建和删除用户。每个角色能做什么由一个集中的授权检查点裁定，而不是散落在各个接口里各判各的。

**阻塞项：** 03 超级管理员初始化与登录会话

**状态：** ready-for-agent

- [ ] 三种角色落地：超级管理员、管理员、用户
- [ ] 超级管理员可创建、删除管理员；管理员不能创建管理员
- [ ] 超级管理员与管理员均可创建、删除用户
- [ ] 创建用户时四个标识字段各就各位：账号唯一、用户名称可重复、short_name 按小写唯一、显示名可重复
- [ ] short_name 校验：强制小写，限 a-z 0-9 与连字符，3–30 位，不以连字符或下划线开头结尾
- [ ] **全部受保护接口经由同一个授权检查点裁定权限**，为 05 的归属过滤留出唯一改动点
- [ ] 越权调用返回未授权，且不因资源是否存在而给出不同响应
