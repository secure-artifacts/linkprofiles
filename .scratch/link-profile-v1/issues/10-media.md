# 10：媒体上传与处理

**构建内容：** 用户直接把手机里拍的照片传上来就行，系统自己压缩，不会因为一张八兆的原图把访客的首屏拖垮。想放视频当头图也可以，系统会先拿首帧当封面，视频加载好了再播。

**阻塞项：** 07 个人页内容编辑

**状态：** ready-for-agent

- [ ] 头像与背景图上传后转为 AVIF 为主、WebP 兜底，并生成缩略图
- [ ] 视频仅校验格式、时长与大小，**不做服务端转码**，运行镜像不依赖 ffmpeg
- [ ] 视频超出限制时给出说明具体原因的错误，而非笼统失败
- [ ] 上传视频时在浏览器端用 canvas 抽取首帧作为封面一并提交；抽帧失败则降级为要求用户手动上传封面
- [ ] 公开页先渲染封面图，视频加载完成后才开始播放，**视频不得成为最大内容绘制元素**
- [ ] 视频在页面上自动循环、静音、行内播放
