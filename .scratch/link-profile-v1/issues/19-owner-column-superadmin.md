# 19：后台「归属」列认不出超级管理员

**构建内容：** 超级管理员自己创建的用户，在后台用户列表的「归属」列里要能看出归属于谁。现在显示的是一个破折号，和「查不到归属者」长得一样，看列表的人无从判断这个账号究竟有没有人管。

**阻塞项：** 无（可立即开始）

**状态：** needs-triage

- [ ] 「归属」列能区分三种情形：归属于某个管理员、归属于超级管理员、真正的无归属
- [ ] 真正的无归属继续以红色标签显眼呈现，不被这次改动削弱
- [ ] 超级管理员与管理员两种视角下该列都正确
- [ ] 破折号不再用于表示「归属者存在但认不出来」

## Comments

**发现记录（2026-08-27 验收走查）**

- `UsersPage.tsx:161` 是 `admins.find((a) => a.id === owningAdminId)?.label ?? '—'`。`admins` 这个列表只装管理员，不含超级管理员，所以超管创建的用户在里面永远查不到，落到 `?? '—'`。
- 破折号因此承担了两种含义：这一列的 `label` 为空时也是破折号（`UsersPage.tsx:125`）。真正的无归属走的是另一条分支，红色 `无归属` 标签，那条是对的。
- 需要先定的是显示什么：写「超级管理员」这个角色名，还是写超管的账号/用户名称。前者简洁但多个超管时区分不了，后者精确但把登录用的账号露在列表上——注意 CONTEXT.md 明确「账号仅用于登录，不出现在任何对外页面上」，后台算不算「对外」需要拍板。这也是本票挂 `needs-triage` 而不是 `ready-for-agent` 的原因。
