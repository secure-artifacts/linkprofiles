# 05：归属分权与无归属流转

**构建内容：** 管理员从此只看得见自己创建的用户，别的小组的账号与数据一概不可见。某个管理员被删除时，他名下的用户不会变成没人能管的孤儿，而是转为无归属并在后台显眼可见，等待超级管理员重新指派。

**阻塞项：** 04 三级角色与用户管理

**状态：** ready-for-agent

- [ ] 用户持有可空的归属管理员外键；创建者自动成为归属管理员
- [ ] 管理员的**每一个**接口都只返回归属于自己的用户，包括列表、详情、编辑、删除与数据分析
- [ ] 管理员访问非名下用户的任一接口均被拒绝
- [ ] 超级管理员不受归属限制，可见全部用户
- [ ] 删除管理员后，其名下用户的归属置空而非连带删除
- [ ] 无归属用户仅超级管理员可见，后台以显眼状态呈现，可重新指派给某个管理员
- [ ] 改动集中在 04 建立的授权检查点，不逐个接口重复实现过滤
