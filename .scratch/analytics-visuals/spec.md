# 数据分析第二阶段：可视化概览

## 目标

在单个个人页的详细分析中，先用可比较的图形回答三个问题，再保留现有明细表用于下钻：

1. 哪些来源带来访问，以及这些访问转化为多少联系点击。
2. 访客主要来自哪些国家，各国联系转化情况如何。
3. 哪些联系方式被点击最多，它们主要由哪个来源带来。

## 范围

- 只调整单个个人页的详细分析视图。
- 使用现有 `crossBreakdowns` 数据，不改变统计口径、数据库结构或事件采集。
- 图形概览之后继续保留来源 / 国家 / 联系方式联动明细。
- 无数据、未知国家和小屏幕均须可用。

## 验收

- 来源排行同时展示进入页面、联系点击和联系转化率。
- 国家热力图按进入页面深浅着色，并列出主要国家及联系点击。
- 联系方式排行展示总点击、占比和主要来源。
- 管理端 typecheck 与 build 通过，部署后健康检查正常。
