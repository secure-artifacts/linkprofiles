# 管理员只能管理自己创建的用户

系统是内部自用、无公开注册的，本可以让所有管理员看见所有用户。但选择了按归属分权：创建用户的管理员成为其**归属管理员**，管理员只能看见并管理归属于自己的用户，超级管理员不受此限。理由是多个运营小组各带各的账号，互不干涉。

## Consequences

- 用户表需要一个可空的归属管理员外键，所有后台列表与数据分析查询都必须带上这个过滤条件；漏掉一处就是越权。
- 归属管理员被删除时，其名下用户转为**无归属**（外键置空），仅超级管理员可见，可再指派。选择置空而非自动转移，是为了让「这批账号需要重新分配」变成一个显式可见的状态，而不是悄悄挂到某个超管名下再没人过问。
- 代价是无归属的用户如果没人去指派，会一直停在那里没人管，需要在后台把这个状态做得足够显眼。
