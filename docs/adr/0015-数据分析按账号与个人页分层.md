# 数据分析按账号与个人页分层

数据分析的首要上下文是分析对象，而不是图表类型。无筛选入口对管理员呈现可见账号的表现列表；进入账号后呈现该账号的总指标、趋势和个人页排行；进入个人页后才加载来源、国家、设备、时段与条目的完整细分。

原因：个人页是独立投放与埋点资产。把多个账号或多个个人页的多维数据直接混在一张分析页里，数字虽可计算，却无法回答哪条个人页有效。Kutt 的“一条链接一套统计”提供了可取的导航模型，但本项目继续保留页面浏览 → 点击 → 线索，以及来源 × 国家 × 联系方式的细分。

单页详细分析先用来源转化排行、国家热力图和联系方式排行给出视觉摘要，再提供联动明细下钻。摘要与明细必须使用同一份交叉分析响应，避免两个查询造成数字不一致。世界地图作为本地静态资产随管理端发布，不依赖运行时第三方地图服务。

实现上先按个人页计算统一表现，再折叠为账号行，保证两个层级口径一致。查询深度随层级增加：账号列表只查表现行，账号汇总增加趋势，完整多维查询仅对单个个人页执行。

这条决定不改变 ADR-0006 的纯计次口径，也不改变 ADR-0008 的三级可见范围。
