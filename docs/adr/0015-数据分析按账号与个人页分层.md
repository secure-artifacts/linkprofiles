# 数据分析按账号与个人页分层

数据分析的首要上下文是分析对象，而不是图表类型。无筛选入口对管理员呈现全部可见个人页的总指标、总趋势和跨账号个人页排行，同时保留账号汇总作为辅助筛选；进入账号后呈现该账号的总指标、趋势和个人页排行；进入个人页后才加载来源、国家、设备、时段与条目的完整细分。

原因：个人页是独立投放与埋点资产。运营首先需要知道整体表现以及哪条个人页有效，若必须先进入账号再逐页查看，比较成本过高。因此总览汇总可安全相加的指标、趋势和维度，并把每个个人页作为独立排行项；排行始终标明个人页和所属账号，来源 × 国家 × 联系方式的汇总也明确标注为当前可见范围，避免失去分析对象。

所有分析范围先用来源转化排行、国家热力图、联系方式排行和来源 × 联系方式矩阵给出视觉摘要，再提供联动明细下钻。摘要与明细必须使用同一份交叉分析响应，避免两个查询造成数字不一致。世界地图作为本地静态资产随管理端发布，不依赖运行时第三方地图服务。

实现上先按个人页计算统一表现，再折叠为账号行，保证三个层级口径一致。总览、账号和单页共用交叉维度查询；只有逐条条目列表等单页专属数据才在选择个人页后加载。个人页表现行携带所属账号、第一来源、第一国家和第一联系方式，让总览无需逐行请求即可显示。当前区间与等长上一周期同时返回；星期 × 小时热力图只使用仍有精确发生时间的明细事件，不把已经失去小时信息的日汇总伪造到某个时段。

这条决定不改变 ADR-0006 的纯计次口径，也不改变 ADR-0008 的三级可见范围。
