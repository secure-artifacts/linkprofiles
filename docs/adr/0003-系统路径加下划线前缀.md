# 系统路径统一加 `_` 前缀，根命名空间让给 short_name

个人页地址是 `域名/{short_name}`，占用根路径，会与 `/admin`、`/api`、`/static` 这类系统路径抢地盘。相比维护一份需要持续追加的保留词黑名单，选择把所有系统路径加下划线前缀（`/_admin`、`/_api`、`/_static`），规则退化为一条：short_name 不得以下划线开头。

## Consequences

- 后台地址是 `域名/_admin`，看起来不常规，但换来了整个根命名空间与一条不会遗漏的规则。
- 新增系统路径时必须记得带 `_` 前缀，否则会与某个用户的 short_name 冲突并静默劫持其流量。
