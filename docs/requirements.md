# 功能需求

来源：《短链接网站开发需求 2026年8月26日》.pdf，经 2026-08-26 需求澄清与完整性审核确定。术语一律以 [CONTEXT.md](../CONTEXT.md) 为准，关键决策见 [docs/adr/](./adr/)。

## 背景

TikTok、Instagram 的简介栏只允许放一条链接，而线索实际来自 WhatsApp、Messenger，导致线索流失。需要一个可自定义的个人链接聚合页，把多个渠道收拢到一条链接背后，并统计哪些渠道真正带来了线索。

**本项目不是短链服务**，不提供长 URL 压缩。「短链接」为全项目禁用词。

## 一、账号与角色

无公开注册。

### 初始化

首次启动时读取 `SUPERADMIN_ACCOUNT` / `SUPERADMIN_PASSWORD` 环境变量创建超级管理员；库中已存在超级管理员则跳过（幂等）。

### 权限矩阵

| 能力 | 超级管理员 | 管理员 | 用户 |
| --- | --- | --- | --- |
| 拥有个人页 | 否 | 否 | 是 |
| 创建管理员 | 是 | 否 | — |
| 删除管理员 | 是 | 否 | — |
| 创建、删除用户 | 是 | 是 | — |
| 可见的用户范围 | 全部 | 仅自己创建的 | 仅自己 |
| 代改用户的个人页内容 | 是 | 仅名下 | — |
| 查看用户的数据分析 | 是 | 仅名下 | 仅自己 |
| 重置、修改用户密码 | 是 | 仅名下 | 改自己的 |
| 修改 short_name | 是 | 仅名下 | 否 |
| 设置来源参数透传的全局默认 | 是 | 否 | — |
| 切换数据分析的展示时区 | 是 | 是 | 是 |

### 归属

创建用户的管理员成为其**归属管理员**。归属管理员被删除时，其名下用户转为**无归属**，仅超级管理员可见并可再指派。后台需把「无归属」做成显眼状态，避免账号长期无人管理。详见 ADR-0005。

### 标识字段

四个字段职责互不兼任：

| 字段 | 用途 | 唯一 | 对外可见 |
| --- | --- | --- | --- |
| 账号 | 登录 | 是 | 否 |
| 用户名称 | 后台中文备注，认人用 | 否 | 否 |
| short_name | 个人页 URL | 是（按小写比较） | 是 |
| 显示名 | 个人页上头像下方的名字 | 否 | 是 |

- short_name 强制小写，限 `[a-z0-9-]`，3–30 位，不以连字符或下划线开头结尾。
- 用户被删除后 short_name 进入墓碑表**永不释放**，访问返回 404，防止旧物料上的链接被后来者接走流量。
- 用户被删除后，其上传的媒体文件从磁盘删除；埋点数据保留，历史汇总不断档。

### 批量创建

粘贴来自 Google Sheet 的数据，每行四列，制表符分隔：

```
用户名称	账号	short_name	密码
```

逐行处理：能建的先建，失败行跳过，结果中列出行号与原因（如「第 7 行：账号 mimnz 已存在」）。密码入库一律 argon2 哈希。

### 登录态

服务端 Session + HttpOnly Cookie，30 天过期。删账号、改密码时删除对应 session，立即生效。

## 二、个人页

地址 `域名/{short_name}`。系统路径一律带 `_` 前缀（`/_admin`、`/_api`、`/_static`），见 ADR-0003。

### 可自定义内容

- **布局**：Classic、Hero、Banner、Cutout、Shape 五种，新账号默认 Classic
- **主题**：六套预设（背景渐变 + 按钮色 + 文字色 + 按钮圆角描边成套），新账号默认 Dawn·晨
- **背景图**：可上传。上传后**覆盖**主题的背景渐变，主题的按钮色与文字色仍生效；图上叠一层暗度可调的遮罩（默认 40%）保证文字对比度
- **头像位**：图片，或上传短视频（mp4，≤10MB，≤15s，自动循环、静音、inline 播放）
- **显示名**、**简介**
- **社媒图标**：从内置清单逐个启用，仅限海外平台，**绝对不含大陆 app**。Messenger 为独立图标（指向 `m.me`），与 Facebook 主页分开
- **按钮**：自定义文字 + 可选副标题 + 目标链接，可拖拽排序，链接可随时更换。单页上限 50 个。
  副标题为选填的一行说明（如「通常当天回复」），留空则不渲染
- **按钮不分组**：所有按钮共处一个用户可自由排序的列表，联系类与内容类可混排，页面上没有区段标题。
  两者的视觉分级只由 `is_lead` 决定——联系类渲染为实心卡片，内容类渲染为描边行。**分级靠样式，不靠位置**

### 输入方式

社媒图标按平台提供定制输入，系统负责拼接目标 URL：WhatsApp 填号码拼 `wa.me`，email 填地址拼 `mailto:`，用户不必了解 URL 格式。

### 空状态降级

Hero、Banner、Cutout 依赖头图。用户未上传时，该区域以当前主题的渐变填充，**不回落到其他布局**。

### 移动端优先

公开页流量几乎全部是移动端从社媒跳转而来，性能与排版按移动端优先设计：

- 公开页零 hydration，浏览器不下载也不解析 React runtime，仅一小段原生 JS 负责点击埋点（见 ADR-0004）
- 关键 CSS 内联进 `<head>`，其余异步加载
- 头像、背景图 `preload` + `fetchpriority="high"`
- 视频不得成为 LCP 元素：上传时在浏览器端用 canvas 从首帧抽取封面图一并上传，首屏渲染封面图，视频加载完成后再播放。抽帧失败时降级为要求用户手动上传封面图
- 五种布局均以 375px 为设计基准，桌面端向上适配
- 图片上传后转 AVIF 为主、WebP 兜底，并生成缩略图

### 收录与分享

- 输出 `noindex`，禁止搜索引擎收录
- 保留完整 og 标签，社媒爬虫可正常抓取分享卡片

## 三、后台编辑与实时预览

用户编辑自己的资料时，必须实时看到移动端效果。

- 预览与公开页共享 `packages/profile-ui` 中同一套 React 组件，零实现漂移
- 预览挂在 iframe 内，提供真实的 375px 移动端视口，并隔离 tailwind 与 Ant Design 两套 CSS reset
- 编辑中的草稿状态经 `postMessage` 灌入预览，无需保存即可见
- 尚未上传的图片与视频以 blob URL 传入预览

## 四、数据分析

### 指标定义

- **线索**：对联系类渠道的点击。联系类由每条按钮与社媒图标上的 `is_lead` 标记决定，可在后台逐条修改。默认值：WhatsApp、Messenger、Telegram、email 为是；Instagram、YouTube、TikTok、X、LinkedIn 为否
- **点击**：对任意按钮或社媒图标的点击，线索是点击的子集
- **页面浏览**：个人页被渲染一次
- **点击率**：单个按钮点击 ÷ 页面浏览；另有页面级汇总 = 全部点击 ÷ 页面浏览

**不做任何访客去重，全部纯计次**：同一人刷 10 次页即 10 次页面浏览，连点 5 次即 5 条线索。对外汇报时须说明是次数而非人数。详见 ADR-0006。

### 维度

- 国家、城市（GeoLite2-City 离线库）
- 设备类型（手机／平板／桌面）+ 操作系统
- 来源

### 来源追踪

- 个人页地址可带 `src` 参数投放，如 `域名/mimnz?src=tiktok`，用于区分平台
- `src` 限 `[a-z0-9_-]` 与长度上限，超出即丢弃，避免脏值进入数据库与后台图表
- 按钮的目标 URL 可逐条开启来源透传，超级管理员可设全局默认
- 已知取舍：统一使用 `src` 而非 `utm_source`，因此第三方网站的 GA 无法直接归因，透传仅在目标为自家页面时有效

### 时区

底层一律存 UTC。后台提供展示时区下拉，默认 `America/New_York`（受众所在）。趋势图切天、24 小时分布图分桶均按所选展示时区计算。

### 图表

- 趋势图：预设区间（今天／7 天／30 天／自定义），区间 ≤2 天按小时，否则按天
- 24 小时分布图：所选区间内全部线索汇总到 0–23 点，用于判断发帖引流的最佳时段

### 爬虫处理

社媒 og 爬虫必然抓取公开页且永不点击，会使点击率分母虚高。服务端用 `isbot` 按 User-Agent 识别，**识别为爬虫则不写埋点记录**，页面照常返回，分享卡片不受影响。

### 隐私与保留

- 访客 IP 在写入前解析出国家／城市后即**截断存储**：IPv4 去掉最后一段，IPv6 去掉后 80 位。地域精度无损，规避 GDPR / CCPA 下的个人数据风险
- 明细保留 6 个月，超期按天聚合进汇总表后删除；日汇总永久保留

## 五、明确不做

站内聊天 · 底部常驻联系条 · 按钮分组与区段标题 · 按钮独立追踪短链 · 长 URL 压缩 · 用户自由调色 · 邮件服务 · Redis · 视频服务端转码 · 公开注册 · 计费 · 访客去重与真实人数统计

## 六、技术栈

```
pnpm workspace
├── packages/server       Fastify 5 + 公开页 renderToString 直出 + API
├── packages/profile-ui   公开页 React 组件（5 布局 × 6 主题）+ tailwind 4
├── packages/admin        Vite 8 + React 19 + Ant Design 6 SPA
└── packages/shared       drizzle schema + 共享类型

PostgreSQL + Drizzle ORM（postgres.js 驱动）
Session + Cookie，服务端存储，30 天过期
Docker：app + postgres 两个服务，仅监听 HTTP，TLS 与反向代理交由运维
```

`packages/server` 与 `packages/admin` 均依赖 `packages/profile-ui`，前者用于服务端直出，后者用于 iframe 实时预览。
